# Security Policy

## Supported versions

Only the latest published version of **SmartPantry** is actively maintained.

| Version | Supported |
| --- | --- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a vulnerability

Please **do not publish security vulnerabilities in a public GitHub Issue or Discussion**.

Instead, contact the repository owner privately through GitHub.

A useful vulnerability report should include:

- a clear description of the issue;
- steps to reproduce it;
- affected functionality;
- potential impact;
- screenshots or logs when relevant;
- suggested mitigation, if known.

## Sensitive information

Never post passwords, authentication tokens, private API keys, Supabase service-role credentials, Android signing keystores/passwords or private user data publicly.

Thank you for reporting security issues responsibly.
